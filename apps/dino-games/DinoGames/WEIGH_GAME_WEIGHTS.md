# Weigh Game - Weight Reference Guide

## Weight Scale (1-8)

The game uses a relative weight scale from 1 (lightest) to 8 (heaviest) to allow for future multiple items per side.

## Real-World Weights (for reference)

### People
- **Child (4-6 years)**: ~20 kg (44 lbs) → Game weight: **1**
- **Dad (adult)**: ~70 kg (154 lbs) → Game weight: **7** 🎭 (Silliness: outweighs T-Rex!)
- **Mom (adult)**: ~50 kg (110 lbs) → Game weight: **2** 💪 (Lighter than ALL dinosaurs - realistic and respectful)

### Dinosaurs (Scientific Estimates)
- **Stegosaurus**: ~1,600 kg (1.6 metric tons) → Game weight: **3** (lightest dinosaur, but still heavier than people)
- **Triceratops**: ~7,500 kg (7.5 metric tons) → Game weight: **5**
- **T-Rex**: ~10,000 kg (10 metric tons) → Game weight: **6** (heaviest dinosaur)

### Objects
- **Car**: ~1,750 kg (1.75 metric tons) → Game weight: **4**
- **House**: Small structure/building materials → Game weight: **8** (heaviest)

## Silliness Element 🎭

**Dad (7) > T-Rex (6)** - Dad outweighs the heaviest dinosaur! This adds a fun, silly element that kids will find amusing.

**Mom (2) vs Dinosaurs**: Mom is lighter than ALL dinosaurs (Stegosaurus=3, Triceratops=5, T-Rex=6). This keeps Mom's weight realistic and respectful - she will never appear heavier than any dinosaur. Dad (7) gets the silliness of outweighing T-Rex, but Mom stays grounded in reality.

## Weight Order (Lightest to Heaviest)

1. Child (1)
2. Stegosaurus (2)
3. Car (3)
4. Triceratops (4)
5. T-Rex (5) - Heaviest dinosaur
6. Dad (6) - Outweighs T-Rex! 🎭
7. Mom (7) - 110 lbs, No jokes! 💪
8. House (8) - Heaviest

## Future: Multiple Items Per Side

When adding multiple items per side, weights will be summed:
- Example: Child (1) + Stegosaurus (2) = 3 total
- This would balance with: Car (3) alone
- Or: Child (1) + Child (1) + Child (1) = 3 total

The scale allows for interesting combinations while maintaining realistic relationships.
