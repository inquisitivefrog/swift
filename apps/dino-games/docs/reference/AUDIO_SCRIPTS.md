# Audio Scripts for Recording

## Matching Game Introduction

The matching-game intro is played from the game-selection transition using **`can-you-match-each-dinosaur.m4a`** (in Games/). No separate game-intro file is used.

---

## Game Completion Messages

### Success (All Matches Found)
**File Name**: `success-all-matches.m4a`

**Script Options**:
- "Amazing! You found all the matches!"
- "Fantastic! You're a dinosaur expert!"
- "Perfect! You matched everything!"
- "Wonderful! You did it!"

### Encouragement (Partial/No Matches)
**File Name**: `encouraging-try-again.m4a`

**Script Options**:
- "Great try! Want to play again?"
- "You're learning! Try again when you're ready."
- "Nice effort! You'll get it next time!"

---

**Location**: Record and save to `Assets/Audio/Feedback/` folder
