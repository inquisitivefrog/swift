# Twelve Species per Group — Distinct Morphological Hooks

*Reference for repeat gameplay: one clear, exaggeratable feature per species so image generators and players can tell them apart. Cuteness/friendliness constraints tend to make same-family members look alike; these hooks are for prompts and for in-game “special feature” matching.*

## How to use this

- **Image prompts:** For each species, lead with the **one hook** (e.g. “Quetzalcoatlus, emphasize extremely long neck and huge size”) so “cute and friendly” doesn’t wash out the difference.
- **Match games:** Use the hook as the “special feature” for that creature (e.g. “Long tail” for Rhamphorhynchus, “Globe teeth” for Globidens).
- **Pool size:** 12 per group supports “pick 3” randomness and long time-to-memorize, as you wanted.
- **Scope:** These lists stay within well-known genera; paleobotany, histology, biomechanics, and expert-honor games can stay as separate scope so this doc stays focused on “enough species with distinct morphology.”
