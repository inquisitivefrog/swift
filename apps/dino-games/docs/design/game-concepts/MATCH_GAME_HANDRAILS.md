# Match Game Handrails (Audio)

*Handrail prompts for Match the Dinosaur / Match the Pterosaur. Code looks for these audio keys; alternate keys allow age-appropriate filenames.*

---

## 1. Tap characteristic before selecting a creature

**Match the Dinosaur**
- **Code key:** `pick-a-dinosaur-first`
- **File:** `pick-a-dinosaur-first.m4a` in `Assets/Audio/Feedback/`
- Wording: e.g. "Pick a dinosaur first!"

**Match the Pterosaur**
- **Code key:** `pick-a-pterosaur-first`
- **File:** `pick-a-pterosaur-first.m4a` in `Assets/Audio/Feedback/`
- Wording: e.g. "Pick a pterosaur first!"

---

## 2. Tap dinosaur or characteristic that’s already matched

- **Code key:** `pick-another-one`
- **File:** `pick-another-one.m4a` in `Assets/Audio/Feedback/`

**Age-appropriate wording options (for recording):**
- "I'm already matched!"
- "That one's done! Pick another."
- "Pick another one!"

---

*Code uses `pick-a-dinosaur-first` (Match the Dinosaur), `pick-a-pterosaur-first` (Match the Pterosaur), and `pick-another-one` (both games). Add the three .m4a files to `Assets/Audio/Feedback/` in Xcode.*
