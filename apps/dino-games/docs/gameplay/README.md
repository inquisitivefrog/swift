# Gameplay

Game-specific design, concepts, and reference for Dino Games. Use this folder for per-game knowledge and future gameplay adaptations.

## Contents

**Concept docs** (from original brainstorming) – high-level game ideas and feature design:
- Matching, eating, fossil ID, sound matching, spinner, size comparison, zoom, anatomy, characteristics, level progression, etc.
- See the table in **docs/FILE_INDEX.md** for the full list.

**Implementation & reference** (from the app repo) – design and data for shipped or planned games:
- **GAME_SELECTION_ARCHITECTURE.md** – How game selection and categories work
- **MATCHING_GAME_DESIGN.md**, **MATCHING_GAME_REVIEW.md**, **MATCHING_GAME_LOGIC_REVIEW.md** – Match-the-dinosaur design and reviews
- **MULTIPLE_MATCHING_GAMES.md** – Supporting multiple matching games (e.g. pterosaurs)
- **RACING_DINOSAURS_DESIGN.md** – Racing game design and metrics
- **PTEROSAUR_GAME_PLAN.md** – Pterosaur games plan
- **TOOTHACHE_ASSETS.md**, **NAME_THAT_DINOSAUR_ASSETS.md** – Per-game asset reference
- **WEIGH_GAME_WEIGHTS.md** – Weigh-game data reference

See **docs/FILE_INDEX.md** for the complete index.
